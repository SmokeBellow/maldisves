# 🐠 Мальдивский Покедекс

Игра для двоих на отдых на Furaveri Maldives: отмечаем всех, кого увидели (рыб, черепах, птиц, закаты),
собираем общую коллекцию, закрываем ежедневное бинго и задания. Карточки нарисованы в коде (SVG), реальные фото из Википедии открываются по кнопке в карточке.
Главная: анимированная сцена с пиксельными Машей и Антоном, которая меняется по времени суток на острове (UTC+5).

- Общая коллекция на двоих, синхронизация через интернет (Wi-Fi на вилле)
- Каталог из 83 карточек: рифовые рыбы, гиганты, подводная мелочь, суша и небо, «моменты»
- Бинго 3×3: новая случайная карточка каждый день (одинаковая у обоих)
- 3 задания в день, очки, уровни, значки, итог поездки
- Работает как приложение на телефоне (PWA), офлайн после первой загрузки

Без сборки: чистый HTML/JS. Запуск локально: `python3 -m http.server` и открыть `http://localhost:8000`.

## 1. Включить синхронизацию (Firebase, бесплатно, ~5 минут)

Без этого игра работает, но у каждого телефона своя коллекция.

1. https://console.firebase.google.com → **Add project** (аналитику можно отключить).
2. В проекте: **Build → Firestore Database → Create database** (любой регион, production mode).
3. Вкладка **Rules** — вставить и опубликовать:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{db}/documents {
       match /rooms/{room} {
         allow get, create, update: if true;
       }
     }
   }
   ```
   Список документов (`list`) запрещён, а доступ только по «коду комнаты» — длинный случайный код работает как пароль.
4. **Project settings → General → Your apps → Web (`</>`)**, зарегистрировать приложение и скопировать
   `apiKey` и `projectId` в [`config.js`](config.js). Эти значения не секретны.

## 2. Выложить на GitHub Pages

1. Смёржить ветку в `main` — workflow `.github/workflows/pages.yml` задеплоит сайт.
2. В репозитории **Settings → Pages → Source: GitHub Actions** (один раз).
3. Адрес будет `https://smokebellow.github.io/maldives/`.

## 3. Установка на телефон

Открыть адрес в Safari (iPhone) или Chrome (Android) → «Поделиться → На экран Домой» / «Установить».
При первом запуске выбрать, кто держит телефон: **Маша** или **Антон**. Комната зашита в `config.js` (`ROOM`),
поэтому ничего вводить не нужно. Перед поездкой, пока есть Wi-Fi: **Мы → Скачать реальные фото для офлайна**.

## Как это устроено

- `js/art.js` — рисунки существ (шаблоны форм и цвета), `js/scenes.js` — сцены главной по времени суток, `js/pixel.js` — пиксельные Маша и Антон (цвета в `PAL`).
- `js/data.js` — каталог существ, квесты, уровни, очки. **Правьте под себя.** Фото берутся из англоязычной статьи Википедии (поле `wiki`).
- `js/game.js` — очки, бинго и задания (детерминированно по дате и коду комнаты, поэтому у обоих одинаковые).
- `js/store.js`, `js/sync.js` — локальное хранение и слияние через Firestore REST. Каждая отметка — отдельная запись
  с временем; побеждает более новая, поэтому одновременные отметки не конфликтуют, а работа без сети досинхронизируется позже.
- `sw.js` — офлайн-кэш приложения и фото.
